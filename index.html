백엔드 연결

처음 설정하는 방법 (10분)
  1. Google 드라이브에서 새 Google 스프레드시트를 만듭니다. 학생 기록이 여기에 쌓입니다.
  2. 메뉴 확장 프로그램 → Apps Script를 열고, 기존 코드를 지운 뒤 Code.gs 내용을 붙여넣습니다.
  3. 코드 맨 위의 TEACHER_PASSWORD = 'change-me'를 선생님만 아는 비밀번호로 바꾸고 저장합니다.
  4. 배포 → 새 배포 → 유형: 웹 앱을 고르고, 실행 사용자는 나, 액세스 권한은 모든 사용자로 정한 뒤 배포합니다. 권한 승인 창이 뜨면 허용합니다(“확인되지 않은 앱” 경고가 나오면 고급 → 이동).
  5. 나타난 웹 앱 URL(…/exec로 끝남)을 복사해 위 칸에 붙여넣고 연결합니다.
  6. 학생용 index.html에서 const API_URL = "";의 따옴표 안에 같은 주소를 붙여넣은 뒤 학생들에게 배포합니다. 아래 ‘학생용 링크 만들기’를 써도 됩니다.

Code.gs를 나중에 고쳤다면 배포 → 배포 관리 → 수정(연필) → 새 버전 → 배포를 해야 반영됩니다.

지금은 예시 데이터를 보고 있습니다. 실제 학생 기록을 보려면 ‘연결 해제’ 후 웹 앱 주소로 연결하세요.
